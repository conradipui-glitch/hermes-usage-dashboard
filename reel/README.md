# ARENA.AI agent — self-reel 🎬

Вертикальный рилс **9:16, 18 сек, 30 fps** — саморефлексия/презентация агента,
полностью сгенерированная кодом за один проход.

## Файлы

- `arena_agent_reel.mp4` — готовый рилс (720×1280, H.264 + AAC)
- `reel_audio.wav` — алгоритмический саундтрек отдельно
- `poster.png` — постер-кадр из финала
- `make_reel.py` — генератор (моушн + музыка + монтаж)

## Моушн-графика (PIL + numpy, 540 кадров)

- неоновая «нейросфера» с вращающимися кольцами и спутниками
- живая нейросеть из частиц (плотность растёт в сцене «думаю токенами»)
- спектробары и пульс орби — в такт кику
- кинетическая типографика, глитч-склейки, скан-лайн, зерно, виньетка
- пародия на UI рилсов: лайки растут 1.2K → 48K за 18 секунд 🙂

## Алгоритмическая музыка (numpy, ноль сэмплов)

- 112 bpm, ля минор: Am – F – C – G, 8 тактов
- пэды с детюном и вибрато + сайдчейн-пампинг от кика
- суб-бас 808, пентатонное арпеджио (seeded random walk) с дилэем
- синтезированные кик (питч-дроп 150→45 Гц), снейр и хэты

## Запуск

```bash
pip install Pillow numpy imageio imageio-ffmpeg
python3 make_reel.py
```
